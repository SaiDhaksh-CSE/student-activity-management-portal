Student Activity Management Portal

About the Project
The Student Activity Management Portal is a simple and user-friendly website developed to help students explore university events, activities, and registration opportunities.

Features
- Displays upcoming university events.
- Provides information about student activities.
- Includes an accessible student registration form.
- Allows students to select events and interests.
- Provides form validation using JavaScript.
- Responsive layout for different screen sizes.

Technologies Used
- HTML5 – Website structure and semantic elements.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Form validation and interaction.

Project Structure
- `index.html` – Main webpage.
- `style.css` – Website styling.
- `script.js` – Form functionality.

How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
